## Resumo

A **1.8.0** traz a tela **Tarefas** para os apps. Acompanha a versão **0.6.7** do sistema.

## Destaques

| Área | O que mudou |
|---|---|
| Android | Mais → Tarefas: as que estão com você e cada projeto por seção; tocar no círculo conclui, o campo no fim da seção cria uma tarefa |
| iPhone e iPad | Mais → Tarefas: as que estão com você (atrasadas, abertas, concluídas), concluir e reabrir |
| Computador | Menu da bandeja → Mais telas: Tarefas |
| Sistema (0.6.7) | Tarefas no estilo Asana (lista, quadro, calendário, cronograma, painel, subtarefas, comentários, GitHub Projects), ar Gree em 3D com a temperatura no visor, Acessos e SEO mais completo, Aparência e marca numa aba só, sino que balança com notificação |

## Como atualizar

- **Android**: instale o APK por cima.
- **Computador**: instale por cima.
- **iPhone**: `xtool install ClimaCasa-ios.ipa` (depois de `xtool auth login`), AltStore ou Sideloadly.
