## Resumo

A **1.6.1** acompanha a versão **0.4.5** do sistema: atalho **Código no GitHub** nos apps.

## Destaques

| Área | O que mudou |
|---|---|
| Computador | Menu da bandeja: Código no GitHub |
| iPhone e iPad | Mais → Código no GitHub |
| Android | Mais → Código no GitHub, entregue pela atualização automática (o APK continua o 1.6.0) |
| Sistema (0.4.5) | Som da nave e salto hipersônico para outra dimensão na tela Segurança; botão GitHub no topo do painel |

## Como atualizar

- **Android**: nada a instalar; abra o app duas vezes para receber a atualização.
- **Computador**: instale por cima.
- **iPhone**: `xtool install ClimaCasa-ios.ipa` (depois de `xtool auth login`), AltStore ou Sideloadly.
