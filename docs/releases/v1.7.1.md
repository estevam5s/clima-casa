## Resumo

A **1.7.1** corrige o erro do app Android ao abrir e traz a tela **Uso do sistema** para os apps. Acompanha a versão
**0.5.8** do sistema.

## Destaques

| Área | O que mudou |
|---|---|
| Android | Corrigido: ao abrir o app aparecia "rota não encontrada"; agora abre direto no Início (ou no login) |
| Android | Mais → Uso do sistema: tempo de uso por pessoa e por tela |
| iPhone e iPad | Mais → Uso do sistema |
| Computador | Menu da bandeja → Mais telas: Uso do sistema |
| Sistema (0.5.2 a 0.5.8) | Agente em qualquer computador (Windows, Mac, Linux, Raspberry Pi, Docker), backup agendado e avançado, feriados na agenda, mapa 3D de 360p a 8K, Raspberry Pi em 3D, uso do sistema por pessoa, Rede ao vivo |

## Como atualizar

- **Android**: instale o APK por cima. Quem já tem a 1.7.0 recebe a correção sozinho ao abrir o app duas vezes (atualização automática).
- **Computador**: instale por cima.
- **iPhone**: `xtool install ClimaCasa-ios.ipa` (depois de `xtool auth login`), AltStore ou Sideloadly.
